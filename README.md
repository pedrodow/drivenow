# DriveNow

Site de aluguel de carros (locadora fictícia) feito com Next.js 16, React 19,
Tailwind v4 e Prisma 7.

```bash
npm install
cp .env.example .env
npx prisma migrate deploy
npm run dev   # http://localhost:3000
```

Status do projeto, decisões e plano de deploy: veja [PROJECT_NOTES.md](PROJECT_NOTES.md).
